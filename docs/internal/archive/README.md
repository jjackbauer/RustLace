# History — archive

evidence of earlier porting rounds; it is **not** a description of the current architecture.

at the time and must not be read as an active capability. The current architecture is
[../architecture.md](../architecture.md), [../extending.md](../extending.md) and [AGENTS.md](../../AGENTS.md).
