## How the evidence was collected

Each tutorial's **Verification** command is the command that produced its **Output** block. The
commands were run with `bash -c` from `/tmp`; a Python check read each Markdown file, extracted the
fenced **Output** block, ran the **Verification** command, and compared stdout byte for byte. All
four comparisons reported `match=True`. The plots were written only under `/tmp/plots` (or the
probe directory `/tmp/plots-fresh`); nothing under the repository is generated by a tutorial.

```console

x = symbol("x")
f = x^3 + 2*x
df = diff(f, x)
refused = simplify((x^2 - 1)/(x - 1))

still_refused = simplify((x^2 - 1)/(x - 1))
cancelled = cancel((x^2 - 1)/(x - 1))
assume(x != 0)
fired = simplify(x/x)

EOF
```

## Supporting precision probe

`evalf(sqrt(2), 20)` renders 19 fractional digits because the 20th is zero; asking for 21 resolves
the question. This is the probe behind that sentence in `symbolic.md`:

```console
/tmp/rl-target/debug/lovelace-run --stdin --text <<'EOF'
a = evalf(1/2, 5)
b = evalf(sqrt(2), 20)
c = evalf(sqrt(2), 21)
EOF
```

Verbatim stdout:

```text
= 1.414213562373095048801 (Real)
  _ = 1.414213562373095048801
  a = 0.5
  b = 1.4142135623730950488
  c = 1.414213562373095048801
```
